# 💪 FitLog — Workout Library

A dark, no-nonsense gym companion: pick a lift, lock it into today's plan, and watch the week's work add up.

## Technologies Used
- Next.js (App Router)
- Tailwind CSS + daisyUI
- lucide-react (icons)
- react-hot-toast (toast notifications)

## Key Features
1. Responsive workout library (3-column grid on desktop) with a loading spinner
2. Sort workouts by Duration, Calories or Rating
3. Workout details page with key specs and step-by-step instructions
4. Add to Today's Plan (max 5 lifts) or Save for later, with live navbar counters
5. My Plan page with live Exercises / Minutes / Calories metrics, Mark as Done and Remove
6. Data saved in localStorage, custom 404 page, toast messages

## How to Run
```bash
npm install
npm run dev
```
Open http://localhost:3000
